# 영어 단어 학습·복습 운영 규칙

기준일: 2026-09-27

> 이 문서는 앞으로 학습 파일과 복습 PDF를 만들 때 적용하는 규칙입니다. 날짜별 실제 완료 여부와 오답 목록은 별도 기록에서 확인합니다. 과거 PDF에 적혔다는 이유만으로 학습이나 복습을 완료 처리하지 않습니다.

## 1. 학습 완료와 영역별 진도

- `학습 완료`와 `[암기]`는 서로 다른 상태입니다. 학습 완료는 실제 확인한 범위이고, `[암기]`는 그중 외우기로 선택하거나 복습에서 틀린 항목입니다.
- `진도: 완료`: 해당 DAY 학습 파일의 단어·혼동어휘·어구/숙어·표현 전체를 학습 완료로 기록합니다.
- `진도: 계속`: 단어, 혼동어휘, 어구/숙어의 번호 범위를 각각 독립적으로 관리합니다. 해당 영역에서 마지막으로 보고한 암기 번호나 별도로 밝힌 마지막 학습 번호까지만 학습 완료로 기록합니다. 범위 안의 미선택 항목도 학습은 완료했지만 새 `[암기]`는 붙이지 않습니다.
- 단순히 PDF에 실렸거나 태그가 있다는 이유로 학습 완료로 판단하지 않습니다. 빠른 인출·집중 복습 문제는 학습 완료가 확인된 항목에서만 고릅니다.
- DAY를 다 마치기 전에는 다음 DAY 학습·선별 파일을 만들지 않습니다. 중단 뒤 재개용 복습 결과를 받기 전에도 새 DAY를 시작하지 않습니다.
- 아직 학습하지 않은 기출 제보는 다음 DAY 학습 파일의 후보로 보류합니다. 학습 범위에 실제 포함되고 사용자가 암기 번호로 선택했을 때 복습 간격을 시작합니다.

## 2. 화면 태그와 판정

표시 순서: `*` → `[암기]` 또는 ~~[암기]~~ → `[발음주의]` → `[혼동주의]` → `[빈출]` → `[토익]`.

| 표시 | 적용 원칙 |
|---|---|
| `*` | 기본형만으로 지금의 뜻을 유추하기 어려운 파생·관련형. 새 항목에 붙일 때는 사용자에게 확인합니다. |
| `[암기]` | 사용자가 모른다고 선택했거나 외우기로 정한 항목, 또는 실제 복습에서 틀린 항목. 네 단계가 끝나기 전에는 활성 상태입니다. |
| ~~[암기]~~ | 1·3·7·14일 네 단계를 실제로 모두 통과했다는 완료 이력. 활성 `[암기]`가 아닙니다. |
| `[발음주의]` | 사용자가 어렵다고 확인한 발음·강세. 필요하면 해당 단어의 미국식 발음을 재생할 수 있는 링크를 제공합니다. |
| `[혼동주의]` | 뜻·철자·발음·품사 등의 비교가 필요한 연결 그룹. |
| `[빈출]` | 일반 영어에서 자주 쓰이는 단어·구조로 확인된 항목. |
| `[토익]` | 일반 학습 항목은 해커스·ETS·서아쌤 세 자료 중 둘 이상에서 **같은 기본형·품사·뜻·필수 구조**로 확인된 경우. 사용자가 보내 준 기출은 세 자료 중 하나라도 동일한 뜻·구조가 확인되면 추가하고, 자료에 없을 때는 서로 다른 기출에서 두 번 이상 확인되면 추가합니다. |

- 태그는 독립적으로 적용합니다. 같은 단어에 여러 태그를 붙일 수 있지만 복습 문제는 한 번만 셉니다. `[다의어]`는 태그로 쓰지 않고 필요한 뜻을 본문이나 메모에 적습니다.
- 태그를 해제할 때는 요청한 태그만 해제합니다. 다른 태그와 실제 복습 이력은 유지합니다.
- `~~[암기]~~`로 완료된 뒤 다시 틀리면 취소선을 풀어 `[암기]`로 되돌리고, 그 오답일에 간격을 초기화합니다.

## 3. 1·3·7·14일 복습

1. 새 `[암기]` 항목의 **다음 실제 복습 포함일**이 1일 단계입니다.
2. 실제 정답으로 현재 보류 단계 **한 단계만** 통과합니다. 다음 3·7·14일 간격은 그 단계를 실제로 통과한 날짜를 기준으로 계산합니다.
3. 예정일이 지났어도 자동으로 통과시키거나 처음부터 다시 시작하지 않습니다. 뒤늦게 풀어 정답이면 미통과 단계 한 개를 통과하고, 오답이면 그날 초기화합니다.
4. 네 단계의 실제 무오답 통과가 모두 확인된 경우에만 `[암기]` 부분을 ~~[암기]~~로 바꿉니다. 다른 태그는 남깁니다.
5. 문제를 만들거나 보내 준 사실만으로 정답·오답·복습 노출·단계 통과를 기록하지 않습니다. 사용자가 완료했다고 밝히거나 결과를 제출한 부분만 반영합니다.

## 4. 복습 100개 선별

한 파일의 구성은 **빠른 인출 60개 + 집중 복습 40개**입니다. 두 파트에 같은 항목을 중복해서 넣지 않습니다. 먼저 학습 완료 여부를 확인한 다음 아래 순서로 선별합니다.

1. 실제 복습 오답
2. 바로 직전에 학습한 단어 중 활성 `[암기]`
3. 복습일이 된 활성 `[암기]`(1일 → 3일 → 7일 → 14일)
4. `*`, `[혼동주의]`, `[발음주의]`, `[빈출]`, `[토익]` 표시 항목
5. 일반 장기복습 항목

- 빠른 인출 오답은 기존 태그와 관계없이 `[암기]`로 활성화하고 오답일에 간격을 초기화합니다.
- 4순위의 다섯 표시는 같은 후보군으로 취급합니다. 실제 복습 이력이 없는 항목 우선 → 마지막 실제 복습일이 오래된 순 → 누적 오답 횟수가 많은 순 → 최근 14일 실제 노출 횟수가 적은 순으로 고릅니다. 여기까지 같을 때만 무작위로 선택합니다.
- 선별을 끝낸 뒤에는 각 파트 안에서 제시 순서를 섞습니다. 혼동 그룹은 비교표에 함께 적어도 실제로 뽑힌 항목만 문제 수와 복습 이력에 셉니다.
- 후보가 100개를 넘으면 우선순위가 낮은 나머지는 다음 복습 후보로 이월합니다.

## 5. 복습 중단과 `학습재개`

- `학습재개`를 받으면 마지막으로 **실제 완료가 확인된** 학습·복습일을 찾습니다. 이후 만들어졌지만 완료되지 않은 PDF는 `미학습`으로 처리합니다. 발송 여부로 간격·정답·오답·실제 노출을 바꾸지 않습니다.
- 미학습 PDF의 항목, 이미 복습일이 지난 활성 `[암기]`, 새로 도래한 활성 `[암기]`를 합쳐 중복을 제거한 뒤 위 우선순위로 **당일자 재개용 복습 PDF** 100개를 별도로 만듭니다.
- 중단 기간이 길어도 `[암기]`를 자동 삭제하거나 전부 초기화하지 않습니다. 재개 뒤 정답이면 남은 단계 하나만 통과하고, 오답인 항목만 그날 초기화합니다.
- 실제 결과가 제출되기 전에는 재개용 PDF를 완료 처리하지 않고 새 DAY 학습 파일도 만들지 않습니다.

## 6. 학습 파일과 핵심 메모

- 표제어를 이해할 때 도움이 되는 기본형·관련형은 **동사 → 명사 → 형용사 → 부사** 순으로 연결하고, 필요한 품사와 한국어 뜻을 함께 적습니다. 예: `decide (v) 결정하다 → decision (n) 결정 → decisive (adj) 결정적인`.
- 규칙적으로 `-ly`를 붙인 부사를 모든 단어 칸에 반복하기보다, 실제 뜻이 달라지거나 형태가 예외적이어서 구별할 필요가 있을 때 적습니다. 의미가 다른 관련형은 차이를 분명히 적습니다. 예: `comprehensible = 이해할 수 있는` / `comprehensive = 포괄적인`.
- 구동사, 동사·형용사와 전치사의 고정 결합, 관용구는 뜻만 나열하지 말고 필요한 구조와 짧은 예문을 함께 제시합니다. 메모는 이해를 돕는 데 필요한 만큼 적되, 출처명은 사용자에게 보이는 메모에 쓰지 않습니다.
- 혼동어휘가 학습 파일 밖에서 추가되면, 사용자가 보낸 단어와 실제로 뜻·발음·차이를 함께 보여 준 연결 단어만 그날 수시 학습 완료로 기록합니다. 이름만 저장한 연결 후보는 미학습 상태입니다. 연결 단어에 `[암기]`를 자동으로 붙이지 않습니다.
- 고정 구조의 일부 단어에만 `[발음주의]`가 있으면 그 구성 단어에 대해 발음 메모와 재생 안내를 합니다.

## 7. PDF 내용과 서식

- 제목 **15pt**, 섹션 제목 **10pt**, 표 본문·예문·해석 **8pt**, IPA·핵심 메모 **7pt**, 표제·안내·표시 태그·쪽 머리글 **6pt**를 유지합니다. 공간이 부족하면 행 높이나 페이지 수를 조정합니다.
- 빠른 인출 TEST와 답안은 동일한 번호·행 높이·좌우 위치와 본문/태그 글씨 크기를 사용합니다. 표의 바깥 테두리와 행·열 경계선을 모두 표시합니다.
- 빠른 인출 답안은 그 페이지에서 끝내고, 집중 복습 상세 정리는 **다음 페이지 첫머리**에서 시작합니다.
- 빠른 인출 및 집중 복습 TEST와 답안은 `1 | 2`, 다음 행 `3 | 4`처럼 가로 우선 배열로 씁니다.
- 집중 복습 40개는 각각 뜻·필수 구조가 드러나는 완성 예문 1개와 한국어 해석 1개를 바로 아래에 놓습니다. 항목과 예문·해석은 가능한 한 같은 페이지에 둡니다.
- 집중 복습 첫 글자 TEST의 영어 쓰기 칸은 각 어절의 **알파벳 수 × 1.5**를 0.5에서 올림한 길이로 잡고, 인쇄된 첫 글자도 전체 칸 길이에 포함합니다. 별도 답안을 TEST 다음 페이지부터 제공합니다.

## 8. 기존 규칙을 바꾸려는 경우

기존에 정한 복습 간격, 선별, 진도 판정, 분량, 서식 중 하나라도 달리할 필요가 생기면 **파일을 만들거나 이력을 바꾸기 전에** 기존 방식을 유지하는 안과 변경안을 선택지로 제시합니다. 각 선택이 어떤 결과를 낳는지 설명하고 사용자의 선택을 받은 뒤 적용합니다. 답을 받기 전에는 임의로 예외를 적용하지 않습니다.
